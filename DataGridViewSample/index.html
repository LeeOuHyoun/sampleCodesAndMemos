DataGridView 샘플

  1. 01. 기본 그리드TreeDocument + columns 만으로 띄우는 최소 구성
  2. 02. 셀 타입 모음콤보(싱글/멀티), 버튼그룹, 프로그레스, 체크, 날짜, 숫자, 색상, 링크, 여러 줄 문자열 + 편집 방식
  3. 03. 툴바 + 그리드setToolbar(JSON) 으로 검색창, 콤보, 버튼 툴바 구성 (동작: ToolbarActions.js)
  4. 04. 정렬 / 필터초기 정렬, 다중 정렬, 사용자 정의 정렬, 정렬 금지, 컬럼별 필터
  5. 05. 실시간 설정값을 바꾸며 바로 확인하는 실시간 설정 + 이벤트 로그
  6. 06. 트리 구조하위 행, 펼치기/접기, 펼칠 때 하위 행 불러오기, 행 아이콘
  7. 07. 컬럼 함수행마다 다른 값, 셀 타입, 콤보 목록, 편집 가능 여부, 조건부 모양, 툴팁
  8. 08. 우클릭 메뉴와 선택onContextualEvent 로 만드는 행 메뉴, 메뉴 버튼 컬럼, 선택 변경 받기
  9. 09. 편집, 저장, 화면 반영셀 단위 즉시 저장과 실패 시 되돌리기, 모아서 저장 (변경 트랜잭션 모드)
  10. 10. 셀 직접 그리기와 상태바onCellRequest + 셀 내용 재사용, buildStatusBar
  11. 11. 드래그앤드롭행 순서 바꾸기, 하위로 옮기기, 놓기 규칙(shouldAcceptDrop), 밖에서 받기, 밖으로 끌어 내기
  12. 12. 헤더와 컬럼헤더 높이, 헤더 숨기기, 2단 헤더(컬럼 그룹), 헤더 직접 그리기, grid.layout 으로 컬럼 숨기기 / 너비 / 고정 / 순서
  13. 13. 사용자 뷰와 화면 상태 저장identifier 로 자동 저장, 꺼내기 / 되살리기, loadCustomViews, 뷰 대화상자, alwaysVisibleFlag
  14. 14. 행 그룹핑groupRows, 그룹 행 제목 / 합계, 그룹 행 거르기, 다시 묶기, 그룹 영역(createGroupingUI)
  15. 15. 서버 사이드 데이터onInfiniteScroll, onDelayedModelDataRequest, dataSource (기본 / virtuallyLoadAllModelItems / 하위 행)

01 ~ 05 는 ENOVIA 서버에서 동작을 확인했습니다. 06 ~ 10 은 원본 소스 분석으로 작성했고 아직 서버에서 확인하지 않았습니다. 11 ~ 15 는 원본 webapps 파일을 로컬에서 띄워 동작을 확인했고, ENOVIA 서버에서는 아직 확인하지 않았습니다.
